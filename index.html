UnoCSS preset-wind4: the theme block order isn't deterministic

Each chip is one variable in :root, :host { … }, coloured by name. Every row should have the same pattern; differing rows mean a byte-different uno.css for the same input.

1. Generator: same tokens, different order

createGenerator({ presets: [presetWind4()] }) runs here in the browser with the same set of tokens, shuffled. The theme block follows the token order.

2. CLI: same files, 20 runs

unocss "src/**/*.ts" --out-file out.css, run 20 times on 60 unchanged files in nested folders before the page started. The CLI keeps tinyglobby's file order, which varies for nested folders.
